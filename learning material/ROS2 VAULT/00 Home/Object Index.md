# Object Reading Rule

Kisi bhi object ke liye pucho:

```text
Who creates it?
What class/type hai?
Kya contain karta hai?
Reference kahan stored hai?
Who uses/calls it?
Runtime me kab exist karta hai?
What comes next?
```
